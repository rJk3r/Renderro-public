# Public Renderro repo

A minimal 3D renderer in C++ using OpenGL, GLFW, GLAD, render pipeline. Renders simple value of standart written models.

## Requirements

- C++17 compiler
- CMake 3.15+
- OpenGL 3.3+
- Ninja

## Dependencies Installation

- Download Ninja (https://github.com/ninja-build/ninja/releases).

## Ninja windows simple-command-install:
```bash
iwr -useb https://github.com/ninja-build/ninja/releases/download/v1.11.1/ninja-win.zip -OutFile ninja.zip; Expand-Archive ninja.zip -DestinationPath C:\Tools\ninja -Force; del ninja.zip; setx PATH "$($env:PATH);C:\Tools\ninja" /M
```
- other libs find self
